# Jarvis-ai
chat with jarvis with a locally hosted ai use commands to communicate and have a desktop assistant,
commands, you have the commands "/open": "Opens a website or an application",

    /weather Displays the current weather

    /help Displays a list of the current commands and their uses
 
    /files Opens your file explorer to a specific folder

    /chat Let's you chat with the ai model

    /memory Lets you view and change things you want the ai model to know

    /time Displays the current time and date

    /quit Stops the program
you can use /exit inside of an ai chat to exit and return back into the home page 
you can use /open which will open a website or an app 

WEBSITES:
To open an website you use the /open command which will ask if you want a website or app, choose website then enter the domain, (the end of a website like .com) and then the website url you want to enter and it will open the website 


APPS:
also uses /open but choose app instead of website this lets you open common windows applications currently but this program is in development 
apps supported are, microsoft paint, calculator, notepad, command prompt, file explorer, task manager, and microsoft edge
later this feature will support every app you have a shortcut for


AI USE:
to use the ai right now you have to have an ai model listening on http://localhost:11434/ like an ollama ai to change the ai model you use go to the section where it lists the jarvis logic and change the ai model to your model. we do not currently support api keys. use this github page https://github.com/ollama/ollama to get ollama setup and running on your pc.
